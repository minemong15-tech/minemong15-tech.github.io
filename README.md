# ZONE · M

두 개의 단일 파일 웹앱을 GitHub Pages로 서비스하는 저장소입니다.

| 경로 | 앱 |
| --- | --- |
| `/zone/` | ZONE — 단수·정전·민방위·재난 비상 알림 앱 |
| `/m/` | M — 채팅·릴스·투표·1분 게임·D-DAY 소셜 앱 |
| `/legacy/` | LEGACY — 매일 한 명의 역사 인물을 읽고 체크하는 기록 앱 |
| `/` | 앱으로 가는 바로가기 페이지 |

- `zone/index.html`, `m/index.html`은 각각 `ZONE-app.html`, `M-app.html` 원본을 그대로 올린 파일입니다(모든 CSS/JS/아이콘이 파일 안에 포함된 단일 파일 앱).
- 배포: `main` 브랜치 루트 → GitHub Pages.
