상황별 행동 요령 (오프라인 저장)

💧 단수할 때▾
  • 물 비축 — 1인당 하루 3L 기준으로 미리 확보 (음용+조리+위생)
  • 수도가 끊기면 변기 뚫기·손 씻기 생략, 마실 물부터 지키기
  • 탄산수는 갈증만 해소, 생수를 우선 섭취
  • 비상 급수시설 위치를 대피소 탭에서 미리 확인
  • 정수 의심 시 끓여서 마시기 (끓일 수 없으면 정수약 없이 보관 금지)
⚡ 정전·노후·정전 경보▾
  • 손전등·보조배터리를 먼저 확보, 촛불은 화재 위험 (사용 시 자리 떠나지 않기)
  • 냉장고 문을 최소로 열기 (냉장 4시간·냉동 24~48시간 유지)
  • 난로·발전기·숯불을 실내에서 쓰면 일산화탄소 중독 위험 — 절대 금지
  • 엘리베이터에 갇혔으면 호출 버튼·119, 억지로 문 열지 않기
  • 복구 후 가전이 여러 대 켜지며 고장 위험 — 하나씩 켜기
🚨 공습·전쟁 (민방위)▾
  • 경보 발생 시 전화 사용 자제 — 회선이 끊기지 않게 문자·메신저 이용
  • 가까운 지하역·지하주차장·건물 지하로 신속 대피
  • 야간에는 조명 차광, 창문에서 떨어지고 유리 파편 주의
  • 비상용품(물·약품·라디오·신분증)을 휴대, 차량은 이동 자제
  • 대피 순서는 어린이·노약자·부상자 우선
🌀 재난·대형 사고▾
  • 정확한 정보 — 정부·지자체 발표와 재난문자만 믿고 소문 퍼뜨리지 않기
  • 침수·붕괴 우려 구역은 즉시 고지대·안전 지대로 이동
  • 단전·단수 지역은 밸브·차단기 내려서 2차 피해 방지
  • 긴급하면 119, 주변 도움 필요하면 이웃과 먼저 연결
